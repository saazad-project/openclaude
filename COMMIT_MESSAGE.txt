## 🚀 Getting Started

1. Set environment variable:
   ```bash
   echo "LONGCAT_API_KEY=your_key" > .env.local
   ```

2. Install and run:
   ```bash
   bun install
   bun run dev
   ```

3. Open http://localhost:3000
