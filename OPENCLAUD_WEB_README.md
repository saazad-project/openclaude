# OpenClaude - AI Coding Assistant

OpenClaude is a modern, full-featured AI coding assistant built with Next.js and Tailwind CSS. It provides a v0.app/bolt.new-like experience for generating, previewing, and deploying code with streaming responses from Longcat AI.

## Features

- **Split-Pane Interface**: Chat on the left, live code preview on the right
- **Real-time Streaming**: See AI responses appear in real-time
- **Code Generation**: Generate complete React/Next.js applications
- **File Management**: Organized file tree with syntax highlighting
- **File Uploads**: Upload images and documents for AI context
- **Mobile Responsive**: Full mobile experience with tab navigation
- **Live Preview**: Built-in iframe for previewing generated code
- **Longcat AI Integration**: Uses OpenAI-compatible Longcat API

## Getting Started

### Prerequisites

- Node.js 20+ or Bun 1.3+
- Longcat AI API key

### Environment Setup

Create a `.env.local` file in the project root with your Longcat credentials:

```env
LONGCAT_API_KEY=your_api_key_here
LONGCAT_API_URL=https://api.longcat.ai/v1  # Optional, defaults to this
LONGCAT_MODEL=longcat-v1  # Optional, defaults to this
```

### Installation

```bash
# Using Bun (faster)
bun install
bun run dev

# Using npm
npm install
npm run dev

# Using yarn
yarn install
yarn dev
```

The application will start on `http://localhost:3000`

## Usage

### Chat with AI

1. Type your request in the chat input
2. Press Enter or click Send
3. Watch responses stream in real-time
4. Generated code appears in the preview panel

### Upload Files for Context

1. Click the "Attach files for context" button
2. Select images or documents
3. They'll be added as context for the AI
4. Send your message - the files are included

### Preview Generated Code

- The preview panel shows files generated by the AI
- Click files in the file tree to view their content
- The preview updates as the AI generates code
- Generated code is syntax-highlighted with language detection

### Clear Conversation

- Click the trash icon to clear all messages and start fresh

## API Integration

### Chat Endpoint

The `/api/chat` endpoint handles all chat requests:

```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Build a React counter app"}
    ],
    "context": "Optional file upload context"
  }'
```

### Response Format

The API returns server-sent events (SSE) with streaming content:

```
data: {"content":"Generated"}
data: {"content":" code"}
data: [DONE]
```

## Customization

### System Prompt

Edit the `CODE_SYSTEM_PROMPT` in `/lib/longcat.ts` to customize AI behavior.

### Styling

- Colors are defined in `tailwind.config.ts`
- Global styles in `app/globals.css`
- Use Tailwind CSS classes for component styling

### Models

Change the model by updating `LONGCAT_MODEL` environment variable or in `/lib/longcat.ts`

## Troubleshooting

### API Key Issues
- Ensure `LONGCAT_API_KEY` is set in `.env.local`
- Check that the API key is valid and has quota

### Streaming Issues
- Verify `LONGCAT_API_URL` is correct
- Check browser console for CORS or network errors
- Try refreshing the page

### Preview Not Working
- Ensure generated code includes valid React components
- Check the file tree for any errors in generated files
- Verify the `entryPoint` is set correctly
